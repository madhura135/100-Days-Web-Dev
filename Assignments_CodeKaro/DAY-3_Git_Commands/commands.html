Git init: To init the git

Git add.: to add all files in git folder

Git commit -m 'msg': to commit the changes to the branch with message

Git log: This shows all the commits done previously

Difference between git reset --soft and git reset --hard

git reset --soft safely undoes commits but keeps your changes saved in the staging area (ready to re-commit), whereas git reset --hard destroys those commits and permanently wipes out all your local changes to restore a clean slate.
