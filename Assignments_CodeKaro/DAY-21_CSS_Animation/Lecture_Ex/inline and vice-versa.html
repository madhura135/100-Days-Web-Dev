Quick Comparison between inline and block elements

Feature Block-Level Elements Inline-Level Elements
Line breaking Block always starts on a new line and forces a line break after it. Inline flows within the text and does not cause a line break.
Width Block stretches automatically to fill the full width of its parent container Inline takes up only as much width as its content requires.
CSS box model Block respects width, height, and all margin / padding properties. Inline ignores width and height; ignores top/bottom margins and padding layout flow.
Nesting Rules Block can contain other block elements and inline elements. Inline can only contain text or other inline elements (cannot contain block elements).
Common Examples block : div,p,h1-h6, ul, li, section Inline :span, a, strong, em, img, button
